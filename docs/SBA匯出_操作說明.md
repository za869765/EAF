# SBA 傳票工坊 — 操作說明（v1.0.0）

> 入口：ACC 會計帳務頁右上「📤 SBA傳票」，或直接開 `/sba.html`（需後台登入）。
> 用途：勾選 EAF 動支單/請購單 → 批次產生支出傳票 → 下載 SBA『匯入傳票』ZIP → 到 SBA 系統匯入。

## 第一次使用（必做）
1. 進「⚙️ 設定」：
   - 填 **SBA 製票人帳號**（你登 SBA 用的帳號，匯入檢核會查）。
   - 填 **用人費用預設人員類別 pkind**（用途別 1XXX 時 SBA 必填；代碼看 SBA 共用項目代碼）。
   - **核對 bcode 對照表**：逐列對照 SBA「常用會計科目設定」的預算科目 4 碼。種子值是推導的，**沒核對前第一批可能被 SBA 退**。
   - 按「💾 儲存設定」。

## 日常流程
1. **📋 選單製票**：預設列近 60 天、已列印、未匯出的單。勾選要付款的單 →
   下方確認製票日期、入帳（已入帳=製票日／未入帳=9991231）、合併方式 → 「⚡ 產生支出傳票」。
   - 保管款（11010202）與基金款（11010201）**自動分開開票**。
2. **🧾 傳票預覽**：逐張檢查。
   - 橘底受款人列＝待補（繳費單型要自己填受款單位名稱）。
   - 付款方式自動判：佳里區農會/佳興分部→存帳；其他銀行→e電匯；繳費單→自領(代繳)。可改。
   - 借方是代收款/應付科目時可按「沖帳」連結原立帳傳票（產 F06）；候選來自已匯入 ACC 的歷史 SBA 傳票，資料只到最後匯入月份，較新的立帳請改在 SBA 端沖。
   - 統一發票（單據=2）須填發票號/日期/金額。
   - 紅色訊息全部清掉才能匯出。
3. **🔁 轉帳傳票**：調整分錄手動編（科目可下拉選歷史科目），借貸平衡後「加入預覽」，與支出傳票同批匯出。
4. **⬇️ 匯出**：選處理日期與批號（2碼，同一天多批要換，如 AA→AB）→「📦 下載 ZIP」→
   到 SBA『匯入傳票轉入作業』上傳 ZIP → SBA『匯入傳票檢核』→『轉製傳票』。
   - SBA 匯入成功後回來按「✅ 標記已匯出」，單子就不會再出現在清單（序號也不會重配）。

## 匯入序號說明
- 序號格式＝年度3碼＋類別1碼＋流水5碼，**從 90001 高段起配**，永遠不會撞 SBA 正式傳票號。
- SBA 轉製後會給正式傳票號（F99 txt），之後照舊把 FNWFRX0090 匯回 ACC 即可對上帳。

## 首批建議
先勾 1 張小額單試匯，確認 SBA 檢核通過（特別注意：bcode 對照、pkind、沖帳關聯）再批次作業。
若 SBA 檢核報錯，把錯誤訊息截圖對照調整（設定頁 bcode／預覽逐欄可改）。
